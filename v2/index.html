How to Use Control Insight Studio

1. Select a Plant G(s): Choose a standard transfer function. For custom plants, select "Custom" and enter numerator/denominator polynomial coefficients separated by commas (highest power first).

2. Tune PID Gains: Use sliders for Kp, Ki, Kd or type values directly. All charts update in real-time.

3. Read the Step Response: Rise time, overshoot, and settling time are computed from the closed-loop simulation. A dashed line marks the reference (1.0).

4. Read the Bode Plots: Gain Margin (GM) and Phase Margin (PM) are marked. PM > 45° typically indicates robust stability.

5. Pole Map: Blue × = dominant pole pair; gray × = other poles. All poles in the LHP (left of imaginary axis) = stable.
